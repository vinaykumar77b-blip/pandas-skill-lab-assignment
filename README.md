# Pandas Skill Lab Assignment

This repository contains 13 Python programs based on
Pandas and NumPy.

## Programs

1. Creating DataFrame and multiplying columns
2. Row-wise and column-wise sum
3. Handling missing values
4. Dropping rows with NaN values
5. Data aggregation
6. Grouping and total sales
7. Merging DataFrames
8. MultiIndex DataFrame
9. MultiIndex grouping and sum
10. Applying functions
11. Applying lambda functions
12. Converting text to uppercase
13. Extracting first three characters

## Requirements

- Python
- Pandas
- NumPy
